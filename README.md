# automatic-happiness

A sleek, responsive calculator built with plain HTML, CSS, and JavaScript. It delivers a polished, modern UI while keeping the logic simple, reliable, and easy to understand.

## ✨ Highlights

- Responsive calculator layout that works well on desktop and mobile
- Support for addition, subtraction, multiplication, and division
- Decimal input, clear, and backspace controls
- Error-safe division by zero handling
- Clean, modern interface with glassy dark styling
- Lightweight project with no dependencies or build step

## 🧠 What it does

This project is a small front-end app that simulates a standard calculator experience. It tracks the current value, pending operator, and chained calculations in real time, then updates the display as the user interacts with the buttons.

The code is intentionally approachable, making it a great example of:

- DOM event handling
- State management in JavaScript
- UI logic for calculator flows
- Responsive styling with CSS

## 🚀 Run locally

Because this is a static web app, you can open it directly in a browser or serve it locally.

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Serve with a local web server

From the project root, run:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
